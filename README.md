# SilentMethyl V2: Sequence-Only Epigenetic Language Modeling

SilentMethyl V2 is a deep learning pipeline engineered to quantify the cis-regulatory impact of synonymous ("silent") mutations in human cancer. By challenging the dogma that synonymous mutations are biologically inert, this model uses a **LoRA-finetuned DNABERT-2** architecture to prove that single-nucleotide typos can physically destroy local transcription factor motifs, alter DNA methylation landscapes, and act as hidden cancer drivers.

This repository represents the transition from a proof-of-concept to a production-grade Discovery Engine, featuring multi-modal fusion (raw DNA + clinical metadata), In-Silico Mutagenesis (ISM), and automated JASPAR/HOCOMOCO biological anchoring.

---

## 📂 Repository Architecture

* `data/`: Contains all datasets. *(Note: Large CSV matrices and Pickled dictionaries should be stored here but are `.gitignore`d to prevent repository bloat).*
    * `raw/`: Unprocessed multi-omics matrices and sequence dictionaries.
    * `processed/`: Cleaned data, tokenized matrices, and `.pkl` vocabulary files generated by the pipeline.
* `scripts/`: The core execution pipeline.
    * `01_build_data.py`: Cleans raw matrices and builds Region/Island vocabularies.
    * `01b_build_real_testing_data.py`: API pipeline to construct multi-omics TCGA datasets from cBioPortal/GDC.
    * `02_train_model.py`: The PyTorch training loop (utilizing LoRA, Multi-modal fusion, and Focal Loss).
    * `03_run_mass_inference.py`: Runs the ISM engine to calculate $\Delta P$ and generate genome-wide Volcano Plots.
    * `04_evaluate_model.py`: Evaluates strict quantitative metrics (RMSE, AUROC, Pearson) on blind holdout sets.
    * `04b_biological_validation.py`: Scans ISM discoveries against JASPAR consensus matrices to prove physical motif destruction.
    * `06_run_negative_control.py`: The Specificity Proof. Runs synonymous permutations on a benign locus to prove the model's structural stability.
* `src/`: Custom PyTorch backend.
    * `model/architecture.py`: Contains the `SilentMethylModel` and the automatic "Triton Surgery" function.
    * `data/dataset.py`: Contains custom PyTorch DataLoaders tailored for DNA sequences and clinical metadata.
* `checkpoints/`: Auto-generated directory for trained `.pth` weights, inference CSVs, and output plots.

## 🛠️ Environment & Hardware Setup

1. **Clone and Install:**
   ```bash
   git clone [https://github.com/yourusername/SilentMethyl.git](https://github.com/yourusername/SilentMethyl.git)
   cd SilentMethyl
   pip install -r requirements.txt
   ```

2. **The "Triton Surgery" Feature (Mac vs. Linux):**
   * **On Apple Silicon (Macs):** Ensure `triton` is commented out or removed from your `requirements.txt`. The pipeline will automatically perform "surgery" on the DNABERT-2 source code to bypass NVIDIA constraints so you can test locally.
   * **On Slurm/Linux Clusters (NVIDIA GPUs):** Ensure `triton` is installed. The model will natively use Flash Attention for exponentially faster training.

## 🚀 Execution Pipeline & Script Commands

Below are the commands for the entire pipeline. 
* **Local Smoke Test:** Uses tiny batch sizes (`2`), no data workers (`0`), and minimal epochs to quickly verify the code compiles and runs on a laptop without crashing.
* **Production / Cluster:** Uses max batch sizes, high CPU workers, and full epochs for deployment on HPC clusters.

### Step 1: Data Engine Initialization
*Cleans the raw TCGA data, builds index mapping, and generates the vocabulary `.pkl` files needed for PyTorch.*

**Local & Production Command:**
```bash
python scripts/01_build_data.py \
    --matrix_path data/raw/Final_Discovery_Dataset_MultiOmnics.csv \
    --dict_path data/raw/DNA_Sequence_Dictionary.csv \
    --base_dir data/processed
```

*(Optional API Fetcher): If you need to build a brand new testing dataset directly from TCGA:*
```bash
python scripts/01b_build_real_testing_data.py --output_csv data/raw/New_TCGA_Cohort.csv
```

---

### Step 2: Model Training (LoRA Fine-Tuning)
*Compiles the custom DNABERT-2 architecture, injects LoRA adapters, splits the data (holding out Chromosome 1 for blind testing), and executes the training loop.*

**Local Smoke Test (1 Epoch, Low Memory):**
```bash
python scripts/02_train_model.py \
    --matrix_path data/processed/cleaned_training_data.csv \
    --dict_path data/raw/DNA_Sequence_Dictionary.csv \
    --region_vocab_path data/processed/SilentMethyl_RegionVocab.pkl \
    --island_vocab_path data/processed/SilentMethyl_IslandVocab.pkl \
    --save_dir ./checkpoints \
    --batch_size 2 \
    --num_workers 0 \
    --epochs 1 \
    --lr 1e-4
```

**Production Cluster (20 Epochs, High VRAM):**
```bash
python scripts/02_train_model.py \
    --matrix_path data/processed/cleaned_training_data.csv \
    --dict_path data/raw/DNA_Sequence_Dictionary.csv \
    --region_vocab_path data/processed/SilentMethyl_RegionVocab.pkl \
    --island_vocab_path data/processed/SilentMethyl_IslandVocab.pkl \
    --save_dir ./checkpoints \
    --batch_size 32 \
    --num_workers 8 \
    --epochs 20 \
    --lr 1e-4
```

---

### Step 3: The Discovery Engine (Mass Inference)
*Runs In-Silico Mutagenesis (ISM) across thousands of variants, calculating the absolute and relative probability shift ($\Delta P$) caused by the mutation. Generates the genome-wide Volcano Plot.*

**Local Smoke Test:**
```bash
python scripts/03_run_mass_inference.py \
    --data_path data/processed/cleaned_training_data.csv \
    --base_dir ./checkpoints \
    --weights_path ./checkpoints/SilentMethyl_Best_Weights.pth \
    --batch_size 2 \
    --num_workers 0
```

**Production Cluster:**
```bash
python scripts/03_run_mass_inference.py \
    --data_path data/processed/cleaned_training_data.csv \
    --base_dir ./checkpoints \
    --weights_path ./checkpoints/SilentMethyl_Best_Weights.pth \
    --batch_size 32 \
    --num_workers 8
```

---

### Step 4: Blind Holdout Evaluation
*Evaluates the trained weights exclusively against the Chromosome 1 holdout set to report final AUROC, RMSE, and Pearson correlation.*

**Local & Production Command:**
```bash
python scripts/04_evaluate_model.py \
    --matrix_path data/processed/cleaned_training_data.csv \
    --dict_path data/raw/DNA_Sequence_Dictionary.csv \
    --region_vocab_path data/processed/SilentMethyl_RegionVocab.pkl \
    --island_vocab_path data/processed/SilentMethyl_IslandVocab.pkl \
    --weights_path ./checkpoints/SilentMethyl_Best_Weights.pth \
    --batch_size 16
```

---

### Step 5: Biological Anchoring (JASPAR Validation)
*Cross-references the most statistically significant mutations discovered in Step 3 against the JASPAR/HOCOMOCO databases to mathematically prove which transcription factor binding sites (e.g., SP1, CTCF) were physically destroyed by the typo.*

**Local & Production Command:**
```bash
python scripts/04b_biological_validation.py \
    --inference_results ./checkpoints/Final_Mutation_Inference_Results.csv \
    --raw_matrix data/raw/Final_Discovery_Dataset_MultiOmnics.csv \
    --save_dir ./checkpoints
```

---

### Step 6: Negative Control (Specificity Proof)
*Tests the model's structural stability. Generates random synonymous permutations on a known benign locus to prove that the model does not hallucinate (proving the null distribution centers at $\Delta P \approx 0$).*

**Local Smoke Test (5 Fast Permutations):**
```bash
python scripts/06_run_negative_control.py \
    --data_path data/processed/cleaned_training_data.csv \
    --base_dir ./checkpoints \
    --weights_path ./checkpoints/SilentMethyl_Best_Weights.pth \
    --n_permutations 5
```

**Production Cluster (100 Rigorous Permutations):**
```bash
python scripts/06_run_negative_control.py \
    --data_path data/processed/cleaned_training_data.csv \
    --base_dir ./checkpoints \
    --weights_path ./checkpoints/SilentMethyl_Best_Weights.pth \
    --n_permutations 100
```
